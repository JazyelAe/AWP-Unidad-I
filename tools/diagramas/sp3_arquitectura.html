DeskData Pro: aplicación ⇄ sistema operativo ⇄ hardware local

1. Aplicación (DeskDataPro.exe = Python + PySide6 empaquetado con PyInstaller)

ventana.pytabla, formulario, filtros y pestañas (Qt Widgets)
grafica.pygráfica de barras con QPainter
models.pyJSON, CSV, respaldos y estadísticas
worker_service.pyQThread que mide CPU, RAM y disco cada 2 s
⇅ llamadas a las APIs del sistema (sin Internet)

2. Sistema operativo Windows

Ventanas e iconobarra de tareas, Alt+Tab
Diálogos nativosAbrir / Guardar como, mensajes
Sistema de archivos%APPDATA%\DeskDataPro\registros.json, respaldos, CSV
Información del sistemapsutil: procesos, memoria y discos
⇅
Procesador (CPU)
Memoria RAM
Disco duro / SSD
Pantalla, teclado y mouse
Una aplicación de escritorio se ejecuta directamente en la computadora y usa sus recursos locales; no depende de un servidor ni de un navegador.
