ConvierteYA: un solo código → Android, iOS y Web

1. Un solo código (JavaScript)

  • App.js + src/: pantallas y componentes
  • Lógica pura: unidades y divisas (pruebas jest)
  • AsyncStorage: historial y respaldo
  • fetch → API Frankfurter (BCE)
  • Platform.OS: solo vibración y avisos cambian
➜

2. React Native + Expo SDK 58

  • <View>, <Text>, <TextInput>, <Pressable>
  • Módulos Expo: Clipboard, Haptics
  • Metro empaqueta el JavaScript
  • Cada plataforma dibuja sus propios componentes
➜

📱 Android

expo prebuild + Gradle → APK. Componentes nativos de Android; Toast y vibración.

🍎 iOS

Mismo código; se compila con Xcode o se abre con Expo Go (no probado aquí: requiere Mac o cuenta).

🌐 Web

react-native-web → HTML y CSS en el navegador; publicada en GitHub Pages.

Una aplicación multiplataforma comparte la misma base de código entre sistemas; solo las diferencias inevitables se resuelven por plataforma.
