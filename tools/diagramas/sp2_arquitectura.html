Funcionamiento de Mi Recetario: cliente ⇄ servidor web ⇄ datos

1. Cliente (navegador)

  • Chrome, Edge, Firefox, Safari
  • Interpreta HTML, CSS y JS
  • Pinta tarjetas, filtros y detalle
  • Valida el formulario
  • localStorage: sugerencias
Petición HTTPS
GET /Mi_Recetario/⇄index.html, CSS, JS

2. Servidor web

  • GitHub Pages (HTTPS)
  • Sirve archivos estáticos desde el repositorio
  • Cada visita descarga la versión más reciente
El navegador
hace fetch()⇄respuestas
JSON

3a. Datos propios

  • data/recetas.json (servido por Pages)
  • 12 recetas con ingredientes y pasos

3b. API externa

  • TheMealDB (REST, otro servidor)
  • search.php?s=chicken → JSON
Sin conexión no hay respuesta del servidor: el navegador muestra su página de error y la app no carga (no tiene service worker ni caché).
Una aplicación web no se instala: vive en el servidor y se usa desde la URL en cualquier sistema operativo.
